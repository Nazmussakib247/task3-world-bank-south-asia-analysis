# Task 6 Final Capstone — South Asia Development Indicators

Prepared by Nazmus Sakib. This project demonstrates data validation, exploratory analysis, stakeholder-focused reporting, feature engineering, regression modeling, chronological holdout evaluation, visualizations, and documented limitations using World Bank WDI data for Bangladesh, India, Nepal, Pakistan, and Sri Lanka (2000–2024).

Download `Task6_Final_Capstone_Project.zip` for the full reproducible project, including the report, source data and metadata, Python script, requirements, validation record, model predictions and metrics, and figures. The separate `Task_6_Final_Capstone_Report.docx` is the evaluator-ready Word report. Model results are retrospective, not causal; the 2020–2024 holdout includes contemporaneous GDP values, so it is not an advance forecast.
